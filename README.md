# Temecula Emergency Maps

Offline maps for when internet and cell service are down:

- **Listen** – emergency alert AM/FM stations, NOAA Weather Radio, open ham repeaters, quick "what to tune to" list
- **Public safety** – fire, sheriff/police, CAL FIRE/CHP, EMS radio sites within 50 miles, with frequencies
- **TV & radio** – broadcast towers from Los Angeles to San Diego

**◎ Where am I** shows your GPS position on the map. GPS works with no cell service.

## Install on Android
1. Open the site in Chrome while you still have internet.
2. Menu ⋮ → **Add to Home screen** (or **Install app**).
3. Open it once from the home screen. After that it works with no internet.
4. Allow location when asked.

Data (Nov 2026): FCC license and broadcast databases, weather.gov NOAA Weather Radio listings, Riverside & San Diego County EAS station lists, RepeaterBook. Map data © OpenStreetMap contributors (ODbL); terrain: Copernicus DEM via Open-Meteo.
